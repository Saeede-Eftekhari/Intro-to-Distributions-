Three Distributions Explorer

Continuous Uniform, Discrete Uniform and Normal — the pattern, the function behind it, the expected value, a sample you generate yourself, and finally the probabilities.

First: what is a distribution?

You already know what a random variable is. A distribution is the next step.

You know thisA random variable is a number you don't know yet — next week's price, the roll of a die, this year's rainfall.
You know this tooA list of the possible values with their probabilities. Value, probability, value, probability.
New todayA named distribution replaces that list with a rule — a function. Give the rule one or two numbers and you have described the whole pattern.
A distribution is simply the pattern behind a random variable: which values tend to show up, and how often. Writing that pattern as a function instead of a long list is what lets us handle prices, times and rainfall — things with far too many possible values to write down one by one.

Two names for that function — and the difference matters

Discrete variableSeparate, countable values (a die shows 1…6). The function is called the probability mass function. Each value carries its own chunk of probability.
Continuous variableAny value in a range (a price, a rainfall total). The function is called the probability density function. Probability is area under the curve, never the height itself.
ParametersThe one or two numbers that pin down which member of the family you have: a and b, or μ and σ.

The pattern, in plain words

Every value in a range is equally likely — and the value can be any number in that range, not just whole numbers.

Our example

The price of a competitor's product is a random variable which is equally likely to be anywhere between $6 and $10. It could be $6.01, $7.4382, or $9.99 — anything in between is just as likely as anything else.

X ~ U(a, b)  →  here X ~ U(6, 10)

Stop — answer this before you generate anything

What does this expected value actually mean? If you simulate one price right now, will it be exactly $8?
Almost certainly not. With infinitely many possible prices between $6 and $10, the chance of landing on exactly 8.000… is essentially zero. E[X] is the long-run average: simulate thousands of prices, average them, and you land near $8. It is the balance point of the flat density — the spot where the shape would tip evenly.

Probability = the area under the density

For a continuous variable we never ask "what is the chance of exactly $8" — that chance is zero. We ask about a range, and the answer is the area of the piece of the shape sitting above that range.

Here the shape is a rectangle, so you can compute the area by hand — no Excel needed:

Area of the shaded rectangle
P(c ≤ X ≤ d) = height × width = 1b − a × (d − c) = d − cb − a

The pattern, in plain words

A short list of values, each one just as likely as the others — and only those values can happen.

Our example

Throwing a die. The possible values are 1, 2, 3, 4, 5, 6, each with probability 1/6. There is no 3.7 and no 0 — the values are separate, countable outcomes.

Continuous vs. discrete: the price on the previous tab was one unbroken line because every value in between was possible. Here we draw separate bars, because the in-between values cannot occur.

X ~ DU(a, b)  →  here X ~ DU(1, 6)

The function behind the pattern

Probability mass function  ·  f(x)
f(x) = 1n   where  n = (b − a) + 1
n is the number of different possible values. For a die, n = (6 − 1) + 1 = 6, so every bar has height 1/6. Here the height is the probability — that is what makes it a mass function rather than a density.
Parametersa = lowest, b = highest
Mean(a + b) / 2
St. dev.√( ((b − a + 1)² − 1) / 12 )
Try a = 1, b = 10 for a ten-sided die. More bars, each one shorter — the same total probability of 1 shared among more values.
The mass function f(x) — bar heights are probabilities

Expected value

Formula
E[X] = Σ x · f(x) = (a + b) / 2
Here
(1 + 6) / 2
E[X]
3.50

This is the same weighted average you already used: each value times its probability, added up. Since every probability is 1/n, it collapses to the midpoint.

Stop — answer this before you generate anything

Can a die ever actually show 3.5? So what is this number telling you?
No — 3.5 is not a possible roll at all. It is the balance point of the six bars. Same lesson as the earthquake example: an expected value does not have to be a value the variable can take. It is the average you approach after many, many rolls.

The pattern, in plain words

Values crowd around a center, and the further you move away — in either direction — the rarer they get.

Our example

The price of product A is a random variable with the distribution N(8, 2). Most prices land near $8. Prices near $4 or $12 happen, but far less often.

Important: the uniform price had a hard floor at $6 and a hard ceiling at $10. The normal has no limits — possible values run from minus infinity to plus infinity, but only a relatively small range has much chance of occurring.

X ~ N(μ, σ)  →  here X ~ N(8, 2)

The function behind the pattern

Probability density function  ·  f(x)
f(x) = 1σ√(2π) e−½((x−μ)/σ)2
Quite complex, in spite of its nice bell shape — and you will never type it by hand. It is a density, just like the uniform, so probability is again the area underneath. The difference: this area has no simple rectangle formula, so Excel computes it for us.

Stop — answer this before you generate anything

The Continuous Uniform tab also had an expected value of $8. If both distributions have E[X] = 8, what is different between them?
Same center, completely different pattern.
U(6,10): every price between $6 and $10 equally likely, nothing outside that window.
N(8,2): prices crowd near $8, and values below $6 or above $10 are possible but less common.

The lesson: an expected value tells you where the center is. It tells you nothing about the shape — which is exactly why we name the distribution instead of only quoting its average.

Part 2 · Now compute a probability

Probability is still the area — but Excel finds it for us

Exactly the same idea as the uniform: the probability of a range is the area under the curve above that range. The only difference is that a bell has no neat rectangle formula, so we hand the job to Excel.

The one function you need
=NORM.DIST(x, mean, standard_dev, TRUE)
With TRUE it returns the area to the LEFT of x — the cumulative probability, P(X < x). Everything else is built from that one number:
P(X > x) = 1 − area to the left  ·  P(c < X < d) = area left of d − area left of c

The shaded area is the probability

Your turn — the NOLA rainfall example

The annual amount of rainfall in NOLA is normally distributed with mean = 65 inches and standard deviation = 15 inches, N(65, 15). Write the Excel formula for each, then compute it.

Getting more than 85 in?

P(X > 85) = 1 − P(X < 85)

=1-NORM.DIST(85,65,15,TRUE)

Getting less than 40 in?

P(X < 40)

=NORM.DIST(40,65,15,TRUE)

Getting between 40 and 80 in?

P(40 < X < 80) = P(X < 80) − P(X < 40)

=NORM.DIST(80,65,15,TRUE)-NORM.DIST(40,65,15,TRUE)

Check your three answers

P(X > 85) = 0.0912
P(X < 40) = 0.0478
P(40 < X < 80) = 0.7936

Notice the third one is by far the biggest — 40 to 80 inches straddles the center, where the curve is tallest and the area piles up.
In Excel, =NORM.DIST(10, 8, 2, TRUE) returns 0.8413. What is that number?

All three side by side

Same recipe every time: a function, one or two parameters, a shape, a balance point, and a way to get probability out of it.

Continuous Uniform
X ~ U(6, 10) · density
E[X] = 8 · probability = area, and the area is a rectangle you compute by hand
Discrete Uniform
X ~ DU(1, 6) · mass
E[X] = 3.5 · probability = add up the bars, count ÷ n
Normal
X ~ N(8, 2) · density
E[X] = 8 · probability = area, and Excel computes it with NORM.DIST
The first and the third have the same expected value of 8 — and look nothing alike. The expected value marks the center. The distribution is what tells you the whole story.
