Four Distributions Explorer

Continuous Uniform, Discrete Uniform, Normal and Binomial — the pattern, the function behind it, the expected value, a sample you generate yourself, and finally the probabilities.

First: what is a distribution?

You already know what a random variable is. A distribution is the next step.

You know thisA random variable is a number you don't know yet — next week's price, the roll of a die, this year's rainfall.
You know this tooA list of the possible values with their probabilities. Value, probability, value, probability.
New todayA named distribution replaces that list with a rule — a function. Give the rule one or two numbers and you have described the whole pattern.
A distribution is simply the pattern behind a random variable: which values tend to show up, and how often. We write that pattern as a function instead of a list of values.

Two names for that function — and the difference matters

Discrete variableSeparate, countable values (a die shows 1…6). The function is called the probability mass function. Each value carries its own chunk of probability.
Continuous variableAny value in a range (a price, a rainfall total). The function is called the probability density function. Probability is area under the curve, never the height itself.
ParametersThe one or two numbers that pin down which member of the family you have: a and b, μ and σ, or n and p.

The pattern, in plain words

Every value in a range is equally likely — and the value can be any number in that range, not just whole numbers.

Our example

The price of a competitor's product is a random variable which is equally likely to be anywhere between $6 and $10. It could be $6.01, $7.4382, or $9.99 — anything in between is just as likely as anything else.

X ~ U(a, b)  →  here X ~ U(6, 10)

The height is the same everywhere between a and b — that is what "uniform" means. Because it is a density, the height is not a probability. Probability comes from the area under this flat line, which you will compute in Part 2.

Try a = 0 and b = 1. The line stays flat — only its position, width and height change. Narrower range → taller line, because the total area must always stay equal to 1.

Stop — answer this before you generate anything

What does this expected value actually mean? If you simulate one price right now, will it be exactly $8?
Almost certainly not. With infinitely many possible prices between $6 and $10, the chance of landing on exactly 8.000… is essentially zero. E[X] is the long-run average: simulate thousands of prices, average them, and you land near $8. It is the balance point of the flat density — the spot where the shape would tip evenly.

Probability = the area under the density

For a continuous variable we never ask "what is the chance of exactly $8" — that chance is zero. We ask about a range, and the answer is the area of the piece of the shape sitting above that range.

The pattern, in plain words

A short list of values, each one just as likely as the others — and only those values can happen.

Our example

Throwing a die. The possible values are 1, 2, 3, 4, 5, 6, each with probability 1/6. There is no 3.7 and no 0 — the values are separate, countable outcomes.

Continuous vs. discrete: the price on the previous tab was one unbroken line because every value in between was possible. Here we draw separate bars, because the in-between values cannot occur.

X ~ DU(a, b)  →  here X ~ DU(1, 6)

The function behind the pattern

Probability mass function  ·  f(x)
f(x) = 1n   where  n = (b − a) + 1
n is the number of different possible values. For a die, n = (6 − 1) + 1 = 6, so every bar has height 1/6. Here the height is the probability — that is what makes it a mass function rather than a density.
Parametersa = lowest, b = highest
Mean(a + b) / 2
St. dev.√( ((b − a + 1)² − 1) / 12 )
Try a = 1, b = 10 for a ten-sided die. More bars, each one shorter — the same total probability of 1 shared among more values.
The mass function f(x) — bar heights are probabilities

Stop — answer this before you generate anything

Can a die ever actually show 3.5? So what is this number telling you?
No — 3.5 is not a possible roll at all. It is the balance point of the six bars. Same lesson as the earthquake example: an expected value does not have to be a value the variable can take. It is the average you approach after many, many rolls.

The pattern, in plain words

Values crowd around a center, and the further you move away — in either direction — the rarer they get.

Our example

The price of product A is a random variable with the distribution N(8, 2). Most prices land near $8. Prices near $4 or $12 happen, but far less often.

Important: the uniform price had a hard floor at $6 and a hard ceiling at $10. The normal has no limits — possible values run from minus infinity to plus infinity, but only a relatively small range has much chance of occurring.

X ~ N(μ, σ)  →  here X ~ N(8, 2)

The function behind the pattern

Probability density function  ·  f(x)
f(x) = 1σ√(2π) e−½((x−μ)/σ)2
Quite complex, in spite of its nice bell shape — and you will never type it by hand. It is a density, just like the uniform, so probability is again the area underneath. The difference: this area has no simple rectangle formula, so Excel computes it for us.

Stop — answer this before you generate anything

The Continuous Uniform tab also had an expected value of $8. If both distributions have E[X] = 8, what is different between them?
Same center, completely different pattern.
U(6,10): every price between $6 and $10 equally likely, nothing outside that window.
N(8,2): prices crowd near $8, and values below $6 or above $10 are possible but less common.

The lesson: an expected value tells you where the center is. It tells you nothing about the shape — which is exactly why we name the distribution instead of only quoting its average.

Part 2 · Now compute a probability

Probability is still the area — but Excel finds it for us

Exactly the same idea as the uniform: the probability of a range is the area under the curve above that range. The only difference is that a bell has no neat rectangle formula, so we hand the job to Excel.

The one function you need
=NORM.DIST(x, mean, standard_dev, TRUE)
With TRUE it returns the area to the LEFT of x — the cumulative probability, P(X < x). Everything else is built from that one number:
P(X > x) = 1 − area to the left  ·  P(c < X < d) = area left of d − area left of c

P(X < 40)

The pattern, in plain words

Repeat the same yes/no trial n times and count how many times you get a "yes". The count is the random variable.

Our example

Assume 40% of Americans agree with the statement "Businesses have too much power over American life." You ask a random sample of 20 people. Each person either agrees (a success) or does not.

The random variable is X = the number of people, out of the 20, who agree. It can be 0, 1, 2, … up to 20 — whole numbers only, so this is a discrete distribution, just like the die.

1 · Fixed number of trialsn = 20 people are asked. Each person is one trial.
2 · Two outcomesEach person agrees (success) or does not (failure).
3 · Same p every timeEach person agrees with probability p = 0.4.
4 · IndependentOne person's answer does not change another's.
X ~ Bin(n, p)  →  here X ~ Bin(20, 0.4)

The function behind the pattern

Probability mass function  ·  f(x)
f(x) = n!x! (n − x)! px (1 − p)n − x   for x = 0, 1, …, n
The fraction counts how many ways x successes can be arranged among n trials; the powers give the probability of one such arrangement. Like the die, each bar height is a probability — a mass function. You will not compute it by hand: Excel does it in Part 2.
Parametersn = number of trials, p = P(success)
Meann · p
St. dev.√( n · p · (1 − p) )
Try p = 0.5: the bars become symmetric around n/2. Try p = 0.1: they pile up near 0. The bars always add up to 1.
The mass function f(x) — bar heights are probabilities

Expected value

Formula
E[X] = n · p
Here
20 × 0.4
E[X]
8.00

Makes sense: if 40% of people agree, then in a group of 20 you expect about 40% of 20 = 8 to agree.

Stop — answer this before you generate anything

If you survey 20 people, will exactly 8 of them always agree? So what does E[X] = 8 tell you?
No. One survey might give 6, the next 10, the next 8. X is random — that is the whole point. E[X] = 8 is the long-run average: repeat the survey many times, average the counts, and you land near 8. (Here 8 happens to be a possible value, unlike 3.5 for the die — but it is still not guaranteed.)

Recap — one random value in Excel, for all four distributions

Each formula gives one random value. Three of them use RAND(), a random number between 0 and 1, and turn it into a value from the distribution; RANDBETWEEN does it in one step. Write the formula once, then drag it down for a sample.

Continuous Uniform · U(a, b)=a+(b-a)*RAND()Price U(6, 10): =6+4*RAND() — any number from 6 to 10.
Discrete Uniform · DU(a, b)=RANDBETWEEN(a,b)Die: =RANDBETWEEN(1,6) — a whole number from 1 to 6.
Normal · N(μ, σ)=NORM.INV(RAND(),μ,σ)Price N(8, 2): =NORM.INV(RAND(),8,2) — most values near 8.
Binomial · Bin(n, p)=BINOM.INV(n,p,RAND())Survey Bin(20, 0.4): =BINOM.INV(20,0.4,RAND()) — a count from 0 to 20.

Watch the order: for the Normal, RAND() comes first; for the Binomial it comes last.

Part 2 · Now compute a probability

Probability = add up the bars — Excel does the adding

Same idea as the die: each bar is a probability, so you add the bars you care about. The bars are no longer all the same height, so we let Excel compute them with one function.

The one function you need
=BINOM.DIST(x, n, p, cumulative)
FALSE → one bar: P(X = x).
TRUE → all bars from 0 up to x: P(X ≤ x).

Careful with the edges. For a discrete variable, P(X ≤ 7) and P(X < 7) are different — the bar at 7 is either in or out. (For the uniform price and the Normal it made no difference, because a single point had zero area.)

Your turn — the survey question

Assume that you believe that 40% of Americans agree with the proposition: "Businesses have too much power over American life." If you take a random sample of 20 people, what is the probability that at most 7 of the people believe business has too much power in American life? Write down the Excel formula that you need.

Step 1 · Name the distribution

X = number of people, out of 20, who agree.
Each person agrees with p = 0.4, so X ~ Bin(n = 20, p = 0.4).

Step 2 · Translate the words

"At most 7" means 7 or fewer: 0, 1, 2, …, 7.
So we want P(X ≤ 7) — the bars from 0 to 7, including 7.

Step 3 · The Excel formula

"Up to and including x" is exactly what TRUE does:

=BINOM.DIST(7,20,0.4,TRUE)

Step 4 · The answer

P(X ≤ 7) = 0.4159

About a 42% chance that 7 or fewer of the 20 agree — even though we expect 8.

Try two more

Exactly 8 agree?

P(X = 8)

=BINOM.DIST(8,20,0.4,FALSE)

At least 5 agree?

P(X ≥ 5) = 1 − P(X ≤ 4)

=1-BINOM.DIST(4,20,0.4,TRUE)
P(X = 8) = 0.1797 — even the single most likely count happens less than 1 time in 5.
P(X ≥ 5) = 0.9490 — "at least 5" includes 5, so we subtract P(X ≤ 4), not P(X ≤ 5).
In Excel, =BINOM.DIST(7,20,0.4,TRUE) returns 0.4159. What is that number?

All four side by side

Same recipe every time: a function, one or two parameters, a shape, a balance point, and a way to get probability out of it.

Continuous Uniform
X ~ U(6, 10) · density
E[X] = 8 · probability = area, and the area is a rectangle you compute by hand
Discrete Uniform
X ~ DU(1, 6) · mass
E[X] = 3.5 · probability = add up the bars, count ÷ n
Normal
X ~ N(8, 2) · density
E[X] = 8 · probability = area, and Excel computes it with NORM.DIST
Binomial
X ~ Bin(20, 0.4) · mass
E[X] = n·p = 8 · probability = add up the bars, and Excel computes it with BINOM.DIST
The uniform price, the normal price and the binomial survey all have the same expected value of 8 — and look nothing alike. The expected value marks the center. The distribution is what tells you the whole story.
